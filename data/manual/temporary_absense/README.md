# 欠場台帳エクスポートの入力

週次・試合日バッチは absence-ledger-partial.csv を直接読みます。
partialという名前ですが、最新の全置換入力として扱い、旧台帳とマージしません。
毎回この固定名で最新エクスポートを置いてください。old/の日付付きファイルは読まれません。

復帰管理は台帳システムを正とします。予測側には、カードは復帰日で影響終了、ケガは復帰予定日前後で影響を減衰させる既存処理があります。
台帳から除かれた選手を旧台帳から補充することはありません。
復帰予定日が空で予定週数がある場合は、既存処理が開始日＋週数で補完します。
影響CSV・日付付きスナップショットは通常バッチで再生成します。
入力がなければ旧台帳に戻らず停止します。ABSENCES_CSVを明示した場合はその指定が優先です。
