# toto 結果の統計用スナップショット

2026-10-17 時点で、[totomark の年別 toto 結果一覧](https://totomark.info/toto/)（2006～2026 年）から読み取った第198回～第1660回の掲載結果を保存したものです。独立した第三者サイトのデータであり、公式結果の全件照合済みデータではありません。`result_year` は掲載ページの年です。国内・海外の対象試合を含みます。

- `observed_results_2006_2026_asof_20261017.csv`: 原資料から取得した回号、13試合の結果列、各年の出典 URL。追記・訂正時はこのファイルを直接上書きせず、新しい取得日を付けたスナップショットを作成します。
- `round_statistics_2006_2026_asof_20261017.csv`: 各回の H/D/A 件数、試合ごとの結果、取消の有無。
- `result_count_distribution_2006_2026_asof_20261017.csv`: 完了した13試合の回について、H/D/A の回内件数別の度数。`fraction = rounds / denominator`。
- `year_summary_2006_2026_asof_20261017.csv`: 掲載年別の回数とゼロ件数。
- `local_eval_cross_check_2006_2026_asof_20261017.csv`: 手元の評価用結果ファイルとの照合。これは出典の正しさを保証するものではありません。
- `manifest_2006_2026_asof_20261017.json`: 取得範囲、元データの SHA-256、集計条件、件数。

結果記号は `1=ホーム勝ち (H)`, `0=引き分け・その他 (D)`, `2=アウェー勝ち (A)`, `＊=取消等`。掲載913回のうち、取消記号を含む47回を頻度計算から除き、完了した866回を分母にしています。取消を含む回は元データと回別ファイルには残しています。

集計の再生成:

```sh
./scripts/.venv/bin/python scripts/build_toto_result_stats.py
```

手元の評価用15回との照合は14回一致、1回不一致です。第1619回は、外部一覧が `2100102121100`、`data/eval/toto_rounds/toto1619/actual_results.csv` が `2102101020111` です。[公式の第1619回結果](https://store.toto-dream.com/dcs/subos/screen/pi04/spin011/PGSPIN01101LnkHoldCntLotResultLsttoto.form?holdCntId=1619&popupDispDiv=disp)では外部一覧の列と一致します。既存の評価用ファイルはこの保存作業では変更していません。第1619回を評価に使う際は、その入力元と対象カードを別途確認してください。

この標本の頻度は、将来の各回の当選確率をそのまま表すものではありません。配券案の比較では、対象期間や対象試合の違いを揃えて評価してください。
