## 次回からの計測

- 通常の週次・当日バッチが修正後の疲労計算・天候取得を実行する。
- 疲労：同日同対戦の予定/実績を重複除去し、チーム名を正規化して移動距離を参照。旧行列の値を優先し、不足チームを全チーム行列で補完する。
- 移動距離は本拠地間の代理値。直前の遠征先からの実移動、飛行機、帰宅日、宿泊を測定したものではない。未参照は欠損フラグを残す。
- 休養時間を時間単位で保存。既存の休養点の係数は保ち、整数日切捨てを廃止。96時間では休養点0となる既存式の仕様を残し、別途96時間以下の警戒条件を観測する。
- 7/14日間の試合数、外部大会の試合数、直前試合時刻、外部大会の負荷未確認を保存。14日を超える中断後は旧試合の負荷持越しをリセットする。
- 保存済みtoto入力のcup区分と採点済み確定結果を照合し、カップ戦出場を取り込む。リーグ側にある同日の同チーム試合は二重加算しない。ACL日程も既存経路で取り込む。
- 全大会の日程網羅を保証するデータはないため、外部大会の網羅性はpartial/unknown。未登録を「カップ戦なし」とみなさない。
- 補足実績は `data/manual/external_match_events.csv` にテンプレートの列で保存する。`status=confirmed`、出典、日時、チーム、大会が必須。`minutes_played` は当該試合のチームの競技時間（延長込み）、`core_usage` は確認した主力投入率0〜1、`event_load` は既存尺度の確認済み負荷。分からない値は空欄。出場時間や投入率から負荷への換算係数は未検証なので自動で作らない。仮説のローテーション表は実績に取り込まない。
- 天候：生データの有効期間を既定6時間にし、取得時刻のない旧キャッシュは再取得。失敗時に古い生データを成功扱いしない。API通信は上限回数まで再試行する。
- 天候は取得時刻・予報/不明の区分・風速単位を保持。欠損を晴れに分類せず、試合時間帯の不足も取得成功にしない。成功率の分母には会場座標欠損も含む。
- キックオフから2時間後までに重なる毎時データについて最大雨量・雨量合計・最大風速を保存。雨量合計は毎時バケットの合計であり厳密な試合中降水量ではない。既存のキックオフ補正は維持し、試合中の悪天候フラグはまず観測に使う。
- 予測側は未来試合について取得時刻不明・24時間超過の予報を天候補正に使わず、unknownを記録。過去データを現在の予報で実測として上書きしない。
- 設定：`WEATHER_CACHE_MAX_AGE_HOURS`（既定6）、`WEATHER_MAX_FORECAST_AGE_HOURS`（既定24）、`EXTERNAL_MATCH_EVENTS_CSV`。

## 試合後の評価

通常の `run_evaluate_round.sh` から条件レポートが自動更新される。単体実行：

```bash
scripts/.venv/bin/python scripts/eval/13_build_condition_feedback.py
scripts/.venv/bin/python scripts/eval/14_build_measurement_audit.py --round toto1650 --season 2026
```

`data/eval/observation_history/reports/conditions/condition_feedback.html` を確認する。
元の購入スナップショット・確率・実結果は変更しない。計測監査CSVは最新結果による事後再計算であり、試合前バックテストではない。

1. **事前条件**：短間隔、カップ戦出場、大雨/強風予報、確率上位の接近を結果と独立に抽出。未確認情報は別欄にする。
2. **結果の意外性**：結果の事前確率・順位・log lossを保存。低確率結果25%以下、本命敗退50%以上を分ける。約30%の第3候補を極端な波乱と同一視しない。
3. **購入の弱点**：正解の採用候補数、採用しなかった選択肢の確率合計、20%以上の選択肢の欠落、60%未満の全候補固定を監査する。閾値は暫定の観測用。
4. **横断確認**：条件あり/なし/不明別に、試合数・確率精度・全候補取りこぼし率を集計する。10候補を独立した10試合として扱わない。条件間の重なりや相手の強さがあるため、因果効果とは解釈しない。
5. **フィードバック**：まず欠損・重複・時刻・単位の不具合を直す。予測係数や分散ルールの仮説は次回の結果が出る前に固定し、同じ候補数で救済/新規取りこぼし/最高的中を比較する。複数回・別の開催回で確かめてから採否を判断する。今回に合わせた一括逆張りや自動再学習は実装していない。
