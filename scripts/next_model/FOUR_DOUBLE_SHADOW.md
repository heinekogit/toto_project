# 4ダブル方式（廃棄済みv3.0構想の履歴・比較対象）

この資料とコードは旧実験の再現用。v4.0のD候補数・ダブル数・配券方法の前提にしない。現行設計はリポジトリ直下の `BUYPLAN_V4_0.md` を参照。

既存v2.5 C95の購入処理とは独立している。4ダブル用の候補00は、各試合のH/Aの高確率側を採用する。既存の3択argmax参照券と異なり、Dが首位でもH/Aを選ぶ。元のH/D/A確率は変更しない。

旧方式の標準選考は `four_double_selection_shadow.select(features)`：P(D)上位4。各試合にDだけ追加し16口・1,600円へ展開する。残り9試合は固定。既存候補01〜10の配分は使用しない。

構造補正は2案だけ比較する。B1は同点中の0–0・1–1構成比。B2はB1に低得点とH/A拮抗の積、優勢側1点差集中と低得点同点の相対質量の積を追加する。0–0等をそのまま加算せず、過去データのP(D)二次式による残差を利用する。固定logit(P(D))に対し構造係数をL2=10で学習し、順位用の変更量を±0.01以内に抑える。39試合以上の先行開催だけで学習する。全設定は暫定で、今回の評価結果による再調整はしない。不採用側H/A確率は診断に限る。

再検証コマンド：

```sh
./scripts/.venv/bin/python scripts/next_model/validate_four_double_selection.py
```

出力は `data/reports/four_double_selection_shadow/`。試合前生成のハッシュ証跡、全特徴量、選考変更、D捕捉数、16口の的中数、モデル13的中確率を記録する。現在開催の結果は選考後に採点する。構造設計時に過去結果が既知であるため、時系列検証を独立した将来検証と扱わない。

今回の共通評価期間1665・1668回では、AはD5試合中3捕捉、B1/B2は各2捕捉。改善は確認できなかった。過去の順位和による1665回単独比較も旧実験記録として残す。旧Aを今後の標準選考にしない。
